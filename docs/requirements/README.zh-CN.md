# 需求管理

[English](README.md) | [简体中文](README.zh-CN.md)

本目录是 TraceHub 版本范围和验收条件的事实来源。GitHub Issues 负责跟踪交付，
不能定义或扩大版本范围。

## 规则

- 每项需求使用全局且永久的 `REQ-001` 格式编号。
- 即使需求被移除，编号也不得复用。
- 需求只描述用户可观察行为、明确的范围外事项和可验证的验收条件，不规定实现方式。
- 状态只能是 `Draft`、`Accepted`、`Released` 或 `Removed`。
- 新增或改变用户可观察行为时，必须先接受相应需求，再开始实现。
- 需求正文和中文翻译必须在同一变更中更新。
