# TraceHub v0.1.1 Requirements

[English](v0.1.1.md) | [简体中文](v0.1.1.zh-CN.md)

Status: Draft

## Goal

An authorized administrator can use the existing session-deletion operation
without accidental or partial deletion. This patch does not add a new product
capability or change which local sessions are synchronized.

## Requirements

### REQ-012: Delete a shared session safely

Status: Draft

An authorized administrator can permanently delete an existing shared session,
but TraceHub requires explicit confirmation before changing stored data.

Acceptance criteria:

- The operation identifies the source device and session UUID and does not begin
  without affirmative confirmation of both values.
- The confirmation displays identifying metadata but not complete session
  content, credentials, or complete tool output.
- Missing or declined confirmation leaves the session unchanged.
- A successful deletion removes the encrypted source chunks, derived events,
  and search index entries in one transaction.
- After successful deletion, the session is unavailable through listing,
  search, details, paged reading, tool output, and export.
- A failed deletion leaves all session data available in its state before the
  operation; it never exposes a partially deleted session.

## Out of scope

- Changing the local Codex directories included by synchronization.
- Aligning server deletion with local archiving or local file removal.
- Preventing a later ordinary synchronization from sharing a local file again.
- An explicit re-share operation.
- Restoring a shared session to Codex.
- New browsing, filtering, pagination, or fork-query behavior.

## Version acceptance

- Verify that omitted or declined confirmation does not change stored data.
- Delete a known session and verify that encrypted source chunks, derived events,
  search results, tool output, and export are unavailable.
- Inject a storage failure and verify that no part of the session is deleted.
- Verify that existing synchronization, search, and reading behavior is
  unchanged.
- `make check`, `actionlint`, and `git diff --check` all pass.
