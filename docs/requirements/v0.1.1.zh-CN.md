# TraceHub v0.1.1 需求

[English](v0.1.1.md) | [简体中文](v0.1.1.zh-CN.md)

状态：Draft

## 目标

经过授权的管理员可以使用现有会话删除操作，且不会意外删除或只删除
部分数据。该补丁版本不增加新产品能力，也不改变本地会话的同步范围。

## 需求

### REQ-012：安全删除共享会话

状态：Draft

经过授权的管理员可以永久删除已存在的共享会话，但 TraceHub 在改变
已保存数据前必须要求明确确认。

验收条件：

- 操作明确标识来源设备和会话 UUID，并且只有在用户明确确认这两个值后
  才开始改变数据。
- 确认信息可显示身份元数据，但不得包含完整会话正文、凭据或完整工具输出。
- 缺少确认或用户拒绝确认时，会话保持不变。
- 删除成功时，在一个事务中删除加密源分块、派生事件和搜索索引项。
- 删除成功后，会话不能再通过列表、搜索、详情、分页阅读、工具输出或导出访问。
- 删除失败时，全部会话数据保持操作前的状态，不会出现部分删除的会话。

## 范围外事项

- 改变同步所包含的本地 Codex 目录。
- 将服务端删除与本地归档或本地文件删除对齐。
- 阻止后续普通同步再次共享仍存在的本地文件。
- 显式重新共享操作。
- 将共享会话恢复到 Codex。
- 新的浏览、筛选、分页或 fork 查询行为。

## 版本验收

- 验证未确认或拒绝确认时不会改变已保存数据。
- 删除一个已知会话，并验证加密源分块、派生事件、搜索结果、工具输出和导出
  全部不可用。
- 注入存储故障，验证会话的任何部分都没有被删除。
- 验证现有同步、搜索和阅读行为保持不变。
- `make check`、`actionlint` 和 `git diff --check` 全部通过。
