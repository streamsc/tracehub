# Requirements

[English](README.md) | [简体中文](README.zh-CN.md)

This directory is the source of truth for TraceHub version scope and acceptance
criteria. GitHub Issues track delivery; they do not define or expand scope.

## Rules

- Every requirement has a global, permanent ID in the `REQ-001` format.
- IDs are never reused, including after a requirement is removed.
- A requirement describes user-observable behavior, explicit exclusions, and
  verifiable acceptance criteria. It does not prescribe an implementation.
- The only states are `Draft`, `Accepted`, `Released`, and `Removed`.
- New or changed user-visible behavior requires an accepted requirement before
  implementation.
- Requirement and translation changes must be submitted together.
